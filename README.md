# Mon petit univers

Une expérience d'anniversaire React + Vite, sans backend.

## Lancer le projet

```sh
npm install
npm run dev
```

Pour vérifier la version déployable :

```sh
npm run build
npm run preview
```

Vercel peut déployer le projet avec la commande `npm run build` et le dossier de sortie `dist`.

## Photos

Les huit photos du dossier `Images/` ont été copiées sans modification dans `public/images/` sous les noms `1.JPG` à `8.JPG`. Les quatre premières apparaissent dans les deux doubles-pages du livre; les huit sont utilisées dans le cœur final de 26 cartes.
Pour remplacer une photo, remplace le fichier correspondant dans `public/images/`. Les chemins, textes et nombre de cartes se règlent dans `src/data/content.js`. Les originaux du dossier `Images/` restent intacts.
